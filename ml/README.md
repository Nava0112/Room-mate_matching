# ML pipeline

The training script preserves the preprocessing and scoring logic from
`roommate_matching (1).ipynb`. It downloads the Lifestyle Preferences Dataset
when available and uses the notebook's documented synthetic fallback otherwise.

```powershell
python ml/train_and_save.py
```

Artifacts are written to `ml/artifacts/`. Inference loads those artifacts only;
it never refits a scaler, encoder, KMeans model, or Random Forest.

```powershell
python ml/predict.py --profile-a profile-a.json --profile-b profile-b.json
```

The Random Forest target is generated by the notebook's rule-based score, so
the validation metrics measure agreement with that proxy rather than real-world
compatibility. KMeans uses the notebook's centroid-distance method, and cosine
similarity is displayed on a 0-100 scale. The application ensemble weights are
RF 0.50, KMeans 0.20, and cosine 0.30.
